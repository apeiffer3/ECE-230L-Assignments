## Lab Questions

### In plain English describe the function and use of a multiplexer.
A multiplexer considers multiple inputs and provides one of them to the output.
### In plain English describe the function and use of a demultiplexer.
A demultiplexer has an input and provides it to several outputs whilst choosing one at a time for the signal path (there's only 1 signal).
### What other uses might these circuits have? (Think Shannon’s)
cell phone communications or determining which signals to provide to the relevant signal paths such as in audio. It's essentially the base of all of our communications.
